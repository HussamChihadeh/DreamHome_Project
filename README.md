# Dream Home

Dream Home is a full-stack real estate and furniture web application that lets users search for properties, tour and purchase them, and then furnish their new home — either by browsing furniture directly or by chatting live with a professional designer.

**By:** Hussam Chihadeh, Mohammad Jamil Chahine
**Instructor:** Dr. Azzam Mourad

## Problem Statement

- No integrated platform combines property listings, furniture options, and designer collaboration
- Inefficient property search
- Inconvenient furniture selection
- Communication and coordination issues between customers and designers

## Key Features

- Property search and filtering
- Property listing and details
- Properties on an interactive map
- Furniture search and filtering
- Furniture recommendations
- Cart management and checkout
- Integrated real-time chat for designer communication
- Property selling
- User profile management
- Administrative pages

## How It Works

1. **Find a property** — search and filter listings, or browse them directly on the map.
2. **Book a tour** — pick a preferred date and time slot and the tour is reserved.
3. **Purchase and personalize** — once a property is purchased, connect with a professional designer through in-app chat to customize furniture for the home.
4. **Furnish it yourself** — or skip the designer and browse the furniture catalog directly, add items to a cart, and check out.
5. **Track everything** — manage your properties, designers, and approval requests from your profile.

## Architecture

Built with Laravel and MySQL on the backend and a Bootstrap/jQuery frontend, following an MVC structure with a RESTful API for data handling between the client and server.
